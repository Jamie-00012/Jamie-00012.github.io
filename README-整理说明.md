# Jamie 作品集整理包

此文件夹整理自当前最终版 `folio-insert-staging`，包含首页与 8 个作品案例实际使用的页面、样式、脚本和媒体资源。

## 预览

安装 Node.js 后双击 `启动预览.cmd`，浏览器打开 `http://127.0.0.1:4174/`。

首页：`index.html`
案例目录：`works/`

## 页面

- Huawei Mate X6 Case
- iPad Mini Folio2
- Samsung Galaxy Watch Band
- Logitech MX Master 4
- Multi-functional Phone Holder
- Xingyu Brand System
- Breakthrough 2020 Editorial
- Festive Tea Packaging

历史素材、测试页和备用 version-b 未复制。
